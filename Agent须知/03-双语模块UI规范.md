# 双语模块 UI 规范

**验收标准**：实现效果须与 [双语模块页面设计参考图.png](./双语模块页面设计参考图.png) 一致；清新校园风格。

## 1. 页面结构（桌面 ≥1024px）

```
┌──────────────────────────────────────────────────────────────┐
│ ← 返回   视频标题（如 TEco Lab 第 7 期）    👁 🔍 ⚙            │
├─────────────────────────────┬────────────────────────────────┤
│  ┌─────────────────────┐   │  逐句列表（可滚动）              │
│  │     视频播放区       │   │  ┌──────────────────────────┐ │
│  │   （Embed / 后期OSS）│   │  │ 1  0:00-0:02             │ │
│  └─────────────────────┘   │  │ Good morning guys.       │ │

│  [下一句][收藏]  (+ 二期)   │  ├──────────────────────────┤ │
│  ┌─────────────────────┐   │  │ 2  0:02-0:05  (当前高亮)  │ │
│  │ 当前句大字幕框       │   │  │ ...                      │ │

└─────────────────────────────┴────────────────────────────────┘
```

## 2. 区域说明

### 2.1 顶栏

- 左：返回 + 视频系列标题
- 中（二期）：模式 Tab — 双语 | 英语 | 中文 | 听写 | 挖空 | 阅读 | 中译英 | 词卡
- 右：显示/隐藏、搜索、设置（MVP 可占位 disabled）
- **MVP 仅实现「双语」模式**，其他 Tab 显示但 `coming soon` 或隐藏

### 2.2 视频区（左上）

- 固定宽高比 **16:9**，圆角容器
- MVP：`storage_type=embed` 时用 iframe（优先 B 站）或 HTML5 `<video>`（OSS 后期）
- 与句轴同步：监听 `timeupdate`，匹配 `video_sentence.start_ms/end_ms`

### 2.3 控制栏（视频正下方）

**MVP 必做**（圆形图标 + 下方文字标签，与参考图一致）：

| 控件 | 行为 |
|------|------|
| 倍速 | 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2 循环或下拉 |
| 全屏 | 视频容器全屏（非整页） |
| 上一句 | `currentIndex - 1`，seek 到该句 `start_ms` |
| 暂停 | toggle play/pause |
| 下一句 | `currentIndex + 1`，seek |
| 收藏 | 调用 `POST /video/{id}/favorite`，心形填充态 |

**二期**（参考图已有，MVP 可不实现逻辑）：隐藏视频、音标、A 点、单句循环、间隔、单句暂停

### 2.4 当前句大字幕框（控制栏下方）

- 大号英文 + 中文对照，居中
- 左上：`当前序号 / 总句数`（如 1/23）
- 右上：收藏 ♡、编辑 ✎（MVP 可隐藏编辑）
- 底部可选：「切换到听写」链接（二期）
- 当前句随播放进度自动更新

### 2.5 右侧逐句列表

- 每行：序号 + 时间范围 + 英文 + 中文
- 当前播放句：**浅灰背景高亮**
- 行内操作（MVP 可选）：播放此句、复制、收藏
- 点击某行 → seek 到该句并高亮
- 独立滚动，播放时当前句 `scrollIntoView`

## 3. 数据依赖

```typescript
interface VideoSentence {
  id: number
  seq: number
  startMs: number
  endMs: number
  textEn: string
  textZh: string
}

interface VideoDetail {
  id: number
  title: string
  coverUrl: string
  storageType: 'embed' | 'oss'
  embedCode?: string
  sourceUrl?: string
  sentences: VideoSentence[]
  favorited: boolean
}
```

## 4. 核心 composable：`useVideoSync`

职责：

1. 维护 `currentIndex`、`isPlaying`、`playbackRate`
2. `timeupdate` → 二分/线性查找当前句
3. `goPrev` / `goNext` → seek + 更新 UI
4. Embed 限制：B 站 iframe API 若不可用，MVP 可改用**自托管 mp4 + 字幕轴**演示，表结构不变

## 5. 4K / OSS 扩展（架构预留，非 MVP）

- `storageType === 'oss'` 时改用 `<video src>` + 同一套句轴逻辑
- 播放器组件抽象 `IVideoDriver`：`embed` | `native`
- 不在 MVP 实现上传与转码

## 6. 平板 / 窄屏

- `< 1024px`：单列布局，顺序为：视频 → 控制栏 → 当前句框 → 句列表
- 控制栏横向 scroll，保证按钮不被挤压
