## 2. 词汇：最优导入方案（多来源 + 快接口）

### 2.1 同行必要字段（前端展示用）

参考扇贝/墨墨/不背单词，MVP 列表/卡片需覆盖：

| 字段 | 用途 | 优先级 |
|------|------|--------|
| `word` | 主展示 | P0 |
| `phonetic` / `phonetic_us` | 发音引导 | P0 |
| `meaning_zh` | 主释义（可合并多条为「；」） | P0 |
| `part_of_speech` | 词性 n./v. | P0 |
| `exam_level` | cet4 / cet6 | P0 |
| `freq_rank` | 考频排序（数字越小越高频） | P0 |
| `phrases_json` | 短语+释义 `[{en,zh}]` | P1 |
| `example_en` / `example_zh` | 例句 | P1 |
| `audio_url` | 发音（二期 TTS 或词典 API） | P2 |
| `tags` | 如 `core`, `listening` | P2 |
| `source_note` | 合规：词表来源说明 | 合规 |

**不第一期做**：柯林斯完整义项、词根树、真人视频例句（扇贝级）。

### 2.2 表结构扩展（Flyway V8，向后兼容）

在现有 `vocabulary` 上增加（脚本由后端 Agent 实现）：

```sql
-- 示意，以实际 migration 为准
ALTER TABLE vocabulary
  ADD COLUMN part_of_speech VARCHAR(16) NULL AFTER phonetic,
  ADD COLUMN freq_rank INT UNSIGNED NULL COMMENT '越小越高频',
  ADD COLUMN exam_level ENUM('cet4','cet6') NULL COMMENT '与 difficulty 对齐后可合并',
  ADD COLUMN phrases_json JSON NULL,
  ADD COLUMN source_note VARCHAR(128) NULL,
  ADD KEY idx_vocab_freq (exam_level, freq_rank);

-- 每日复习（1B 极简 SM-2）
CREATE TABLE user_vocab_review (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  user_id BIGINT UNSIGNED NOT NULL,
  vocabulary_id BIGINT UNSIGNED NOT NULL,
  familiarity TINYINT NOT NULL DEFAULT 0 COMMENT '0-5',
  next_review_at DATETIME NOT NULL,
  last_review_at DATETIME NULL,
  UNIQUE KEY uk_uvr (user_id, vocabulary_id),
  ...
);
```

`user_vocabulary` 保留：收藏/来源；`user_vocab_review` 专管「今日 20 词」队列。

### 2.3 多来源导入流水线（推荐）

```
┌─────────────────────────────────────────────────────────────┐
│ ① 词表范围（大纲）  JavaProgrammerLB/cet-word-list (MIT)     │
│    → 校验 word 是否在 CET 大纲内                             │
├─────────────────────────────────────────────────────────────┤
│ ② 释义/例句/短语  KyleBing/english-vocabulary json-simple   │
│    CET4/CET6 分文件 → 合并释义、phrases                      │
├─────────────────────────────────────────────────────────────┤
│ ③ 考频排序（可选） 自建：真题高频表 或 按 json 顺序 + 人工表 │
│    → 写入 freq_rank 1..800（第一期只导入前 800）              │
├─────────────────────────────────────────────────────────────┤
│ ④ 脚本 backend/scripts/import_vocabulary.py                 │
│    输出：db/migration/V8__seed_vocab_core.sql 或 CSV bulk    │
│    记录 content_source：name=多源合并, license_note=见下     │
└─────────────────────────────────────────────────────────────┘
```

**来源合规备注（写入 `content_source` / `vocabulary.source_note`）**：

- 大纲词表：教育部考试中心《四六级考试大纲》公开 PDF（仅词形）
- 释义数据：GitHub 社区词库，**站内展示不声称官方**，注明「整理自开源词库，仅供学习」
- **禁止**：爬扇贝/墨墨 API、复制有道词典整库

**第一期数量**：`cet4` 1200 + `cet6` 400 = **1417**（V17 upsert）；二期再扩到 3000+。

### 2.4 API 与性能（前端要快）

| 接口 | 策略 |
|------|------|
| `GET /api/v1/vocabulary/today` | 登录用户；查 `user_vocab_review` where `next_review_at <= now` limit 20；**Redis 缓存 key `vocab:today:{userId}` TTL 5min**，提交复习后失效 |
| `GET /api/v1/vocabulary/{id}` | 单条；Redis `vocab:item:{id}` TTL 1h |
| `GET /api/v1/vocabulary/search?q=` | **仅前缀匹配** `word LIKE 'q%'` + `idx_vocab_word`；limit 20；禁止 `%q%` 全表扫 |
| `POST /api/v1/vocabulary/review` | 更新 familiarity / next_review_at（极简：对+1 天，错+0 天当天再出现） |
| `POST /api/v1/user-vocabulary` | 生词本收藏（已有表） |

**列表 DTO 瘦身**（不要一次返回 phrases_json 全量）：

```json
{
  "id": 1,
  "word": "abandon",
  "phonetic": "/əˈbændən/",
  "partOfSpeech": "v.",
  "meaningBrief": "放弃；遗弃",
  "freqRank": 42,
  "examLevel": "cet4"
}
```

详情接口再返回 `phrases`, `examples`。

### 2.5 前端（1B：每日 20 词）

- 路由：`/vocabulary` 或首页卡片「今日 20 词」
- 交互：卡片翻转（释义）+ 「认识 / 模糊 / 不认识」三键（墨墨简化版）
- 不做：完整词书选择、PK、打卡捐爱心（扇贝级）

## 3. 阅读模拟题：RACE 与商用数据集

### 3.1 RACE 是否可取？

| 用法 | 结论 |
|------|------|
| 直接入库 RACE 原文+题目 | ❌ **不可取**。RACE 许可：**仅非商业研究**；禁止 reproduce / sell / commercial exploit（[CMU RACE](https://www.cs.cmu.edu/~glai1/data/race/)） |
| 下载后「改几个字」上架 | ❌ **高风险**。仍属衍生使用，且你方 VIP 商业化明确违反 NC 精神 |
| 离线当**题型参考**（只看结构，重写成全新篇章+全新题干） | ⚠️ 灰色，**不推荐**作为主力；投入产出不如 VOA+自编 |

### 3.2 推荐内容策略（可商用）

| 来源 | 许可 | 用法 |
|------|------|------|
| **VOA Learning English** 自产文本/音频 | **Public domain**，可教育+商用，需署名 learningenglish.voanews.com | 取 300–400 词短文 → **改写成 CET 长度** → 自写 4 道单选+解析 |
| **LLM 生成 + 人工校对** | `content_source.original` | 与章节主题对齐；必标 `is_mock=1` |
| **Wikipedia CC BY-SA** 段落 | 可商用需署名+相同许可 | 仅作背景知识改写，勿整段复制 |
| Common Crawl CC-BY（过滤 NC） | 需逐条验证 license | 二期半自动；一期不做 |

**第一期篇数**：2 篇（与 2 个 `reading_chapter` 绑定），每篇 4 题。  
**工作流**：VOA/自编英文稿 → 你校对 → Admin/SQL 入库 → P0-1 API。

### 3.3 与 P0-1 开发衔接

- 先 **Flyway V7**：`reading_passage` + `reading_question` + `reading_question_option` 种子 2 套
- 再 `ReadingPassageService` + `/reading/practice/[passageId]`

## 4. 翻译题：5–10 道 quality 标准

| 要求 | 说明 |
|------|------|
| 数量 | 首期 **8 道**（4 cet4 免费 + 2 cet4 + 2 cet6 VIP） |
| 主题 | 经济、教育、文化、科技、社会民生（对齐大纲） |
| 质检 | 每题：题干中文自然、参考答案经母语者/LLM+人工核对、干扰点明确 |
| 入库 | `is_mock=1`，`content_source` = 自编模拟 |
| 关联 | `chapter_id` 绑定技巧章；列表页显示「模拟题」标签 |

**禁止**：复制圣才/易考吧解析文本。

## 5. 备考导航（2A，不做题库）

### 5.1 页面

- 路由：`/exam-guide` 或 `/cet/resources`
- 内容类型：**仅链接 + 说明**，不托管 PDF/听力 mp3

| 区块 | 链接示例 |
|------|----------|
| 官方 | [中国教育考试网 CET](https://cet.neea.edu.cn/) |
| 大纲 | 四六级考试大纲 PDF（neea 附件） |
| 报名/成绩 | neea 对应栏目 |
| 说明文案 | 「本站练习题为自编模拟，非历年真题；真题请以考试院发布为准」 |

### 5.2 数据表（可选）

用 `content_source` + 静态 JSON 即可，无需爬虫：

```json
{ "title": "2025年6月四级考试公告", "url": "https://cet.neea.edu.cn/...", "type": "official_link" }
```

二期可加「考试日历」手动维护。

## 6. 视频：弃 Embed 新路（OSS + 你方下载）

### 6.1 决策对齐

- **新视频**：`storage_type=oss`，`provider=self`，走现有 Admin：`上传 MP4 → parse → 句轴 → publish`
- **旧 Embed 视频**：可保留至替换完成；`useVideoSync` 模拟时钟仅维护旧数据
- **你不做**：继续扩 B 站 Embed 库

### 6.2 素材合规清单（你手动下载时对照）

| 平台 | 可行条件 | 注意 |
|------|----------|------|
| **YouTube** | 创作者设为 **Creative Commons BY**（高级搜索可筛） | 允许商用但需**署名**；平台 ToS 对「下载」有争议 → 建议保留频道链接+`license_note` 截图备查；优先选「官方允许下载」或联系创作者 |
| **TikTok** | 默认**不可**假定商用 | 需创作者书面授权或平台明确商用许可；**不建议**第一期依赖 TikTok |
| **VOA / TED** | TED 官网条款、VOA 公有领域自产内容 | VOA 仅自产部分；勿带 AP/Reuters 画面 |

入库必填：`video.license_note`、`content_source`（频道 URL、CC BY、下载日期）。

### 6.3 技术无需改架构

现有流水线已支持 OSS；你下载后本地走 Admin `POST /admin/videos/parse` 即可。  
前端 `pages/video/[id].vue` 对 `storage_type=oss` 用原生 `<video>`（与 AGENT §8.4 一致）。
