## 1. 现状快照（截至 v0.3）



| 能力 | 阅读 | 翻译 |

|------|------|------|

| 技巧章节 | ✅ 2 章 HTML | ✅ 2 章（1 章 VIP） |

| 模拟练习 | ✅ 2 篇×4 题（`V7`） | ✅ **8 道**（`V10`，含 VIP/cet6） |

| AI | — | ✅ DeepSeek + fallback；15 分制 + 分档 |

| 学习闭环 | ⚠️ 无章节进度、无阅读提交历史表 | ✅ 提交历史 `GET /submissions/mine` |

| 内容运营 | ❌ 无 Admin 录题 | ❌ 无 Admin 录题 |



**结论**：阅读已形成「技巧 → 模拟练 → 即时判分」；翻译已形成「练 → AI 评 → 历史」，**题量不足**是上线前主要短板。
